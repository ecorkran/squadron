Run the following command and display the results:

`sq benchmark $ARGUMENTS`

Subcommands for fix cases: `fix-cases build --set NAME [--repo PATH] [--commit SHA ...] [--keep]` (discover the repository's closing commits, qualify each as a fix case in a sandbox, write the case set, and print the yield report), `fix-cases show COMMIT|CASE_ID [--repo PATH]` (the latest qualification record: environment digest, each hidden test with its verdict and detail, superseded and excluded tests, and the frozen task text), and `yield [--repo PATH ...] [--json]` (qualified and rejected counts per project and pooled, with whether the qualified cases can separate two configs). `fix-cases build` runs installs and test suites and reads issues through `gh`; run it only when the user has asked for it.

Replay subcommands: `run --set NAME --model ALIAS [--model ALIAS ...] --max-cost USD [--set-version N] [--samples K] [--max-cost-per-replay USD] [--case CASE_ID ...] [--retry-harness] [--keep] [--repo PATH]` (run the producer on each case of a set under each model, print the stated cost bound first, then one line per replay and a summary; exit 0 complete, 2 partial at the run cap, 1 refused or stopped) and `replay-show RECORD_ID [--diff] [--repo PATH]` (a stored replay record, or with `--diff` its stored diff exactly).

Grading subcommands: `grade BENCHMARK_ID --max-cost USD [--review-model ALIAS] [--review-cost USD] [--repo PATH ...] [--case CASE_ID ...] [--retry-harness] [--keep]` (grade each case's reference and every committed replay of a benchmark in a fresh sandbox, print the stated cost bound first, then one line per subject and a summary; exit 0 complete, 2 stopped at the run cap, 1 refused or stopped; it runs installs, test suites and review calls that cost money, so run it only when the user has asked for it) and `report BENCHMARK_ID [--json] [--repo PATH]` (a graded benchmark's report: objective grade, paired comparison, checks against the baseline, review findings, cost and time, absences and exclusions, and the measured sample count; `--json` emits the report model).

Slice-case subcommands: `slice-cases build --set NAME [--repo PATH] [--keep]` (qualify each completed slice recorded by `sq metrology slice-ranges` as a slice case in two sandboxes, write the case set, print one line per slice and the slice-case yield rows; exit 0 when the build finished, 1 when no slice ranges are recorded or a harness failure stopped it; it runs installs and test suites, so run it only when the user has asked for it) and `judge BENCHMARK_ID --max-cost USD [--judge-model ALIAS] [--judge-cost USD] [--repo PATH ...]` (judge a benchmark's slice-case implementations pairwise over their diffs, print the stated cost bound first, then one line per pair and a summary; exit 0 complete, 2 stopped at the run cap, 1 refused or stopped; it makes model calls that cost money, so run it only when the user has asked for it).

Other subcommands: `sandbox REV [--suite] [--node ID ...] [--keep]` and `auth-check --model ALIAS [--model ALIAS ...]`.
