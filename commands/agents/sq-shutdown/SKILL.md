---
name: sq-shutdown
description: Shuts down a named squadron agent, or every agent with --all. Use when the user asks to stop, kill, or shut down one or more running agents.
---

# sq shutdown

Run `sq shutdown`, appending whatever the user typed after `$sq-shutdown` as arguments.

Provide an agent name to shut down a specific agent, or use `--all` to shut down all agents.
